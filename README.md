# Hacker Scripts

- [`hackernews/hn_top_articles.py`](hackernews/hn_top_articles.py): Fetches the top 50 Hacker News stories for each month, checks whether each article URL still loads, and finds Wayback Machine snapshots for the dead ones.
- [`media/vidgrab.sh`](media/vidgrab.sh): Downloads media, transcribes the audio with Whisper, and saves a frame at every scene.
